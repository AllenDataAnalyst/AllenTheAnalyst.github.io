Business Problem

Covid 19 data can be difficult to interpret when information is spread across multiple countries, dates, case counts, death totals, and population level metrics.

Users need a clear visual dashboard to quickly understand trends, compare geographic impact, and communicate the pandemic's effect in a simple and interactive way.

Solution

I created an interactive Tableau dashboard that visualizes Covid 19 data through charts, maps, and summary views. The dashboard helps users explore the data, compare locations, and identify major trends more easily.

Key Features

  • Covid 19 case trend visualization
  • Death count and impact analysis
  • Country or region based comparison
  • Interactive Tableau filters
  • Map based visual analysis
  • Clear dashboard layout for public health reporting
