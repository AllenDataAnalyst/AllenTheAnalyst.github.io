Project Overview

This project demonstrates how SQL Server can be used to explore large public health datasets, calculate meaningful metrics, compare countries, and uncover pandemic related trends.

Trend Analysis

Analyzed Covid-19 cases, deaths, vaccination progress, and timeline based changes.

Country Comparison

Compared infection rates, death rates, and population impact across countries and regions.

SQL Analytics

Used joins, aggregations, filtering, calculations, and window functions for deeper analysis.

Business Problem

Covid-19 data contains large volumes of country level, date based records. Without proper SQL exploration, it can be difficult to understand infection trends, death rates, vaccination progress, and population impact across different regions.

Solution

I used SQL Server to explore Covid-19 datasets by joining related tables, calculating key metrics, comparing countries, and identifying trends over time. The project demonstrates how SQL can be used to transform raw public health data into meaningful insights.

SQL Techniques Used

  • SELECT statements and filtering
  • JOIN operations across related Covid-19 tables
  • Aggregations using SUM, MAX, and GROUP BY
  • Calculated fields for infection rate and death percentage
  • Window functions for rolling vaccination totals
  • Common Table Expressions
  • Temporary tables
  • Views for reusable reporting queries
  • Country and continent level comparisons

Key Insights Explored

  • Countries with the highest infection rates
  • Countries with the highest death counts
  • Death percentage by location and date
  • Population percentage infected
  • Vaccination progress over time
  • Global case and death trends
