Business Problem

Banks and lending institutions often manage large volumes of loan records, making it difficult to monitor lending performance, borrower behavior, approval trends, and portfolio health using static reports.

Decision makers need a centralized reporting solution that provides visibility into loan applications, funded amounts, customer demographics, and key lending KPIs.

Solution

I developed an interactive Power BI dashboard that consolidates loan data into a single reporting solution. Users can analyze lending performance, monitor customer trends, compare loan statuses, and evaluate portfolio performance using interactive visuals and filters.

Key Features

  • Loan application analysis
  • Funded amount monitoring
  • Loan approval and rejection trends
  • Borrower demographic insights
  • Loan status analysis
  • Interactive filtering and drilldown
  • Executive KPI dashboard
