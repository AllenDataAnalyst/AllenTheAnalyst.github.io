Project Overview

This project demonstrates how raw and messy data can be cleaned, standardized, and prepared for analytics using SQL Server.

Data Quality

Improved consistency by cleaning and standardizing raw housing data fields.

SQL Transformation

Used SQL logic to update values, split fields, remove duplicates, and prepare data for reporting.

Reporting Ready

Prepared a cleaner dataset that can be used for analysis, dashboards, and business reporting.

Business Problem

Raw housing datasets often contain duplicate records, inconsistent formatting, missing values, and unnecessary columns. These issues reduce data quality, create inaccurate reporting, and make analysis more difficult.

Solution

Using SQL Server, I cleaned and transformed the dataset by standardizing values, removing duplicate records, converting data types, splitting columns, handling missing information, and preparing the dataset for reporting and analytics.
